## `AtsCategoryScore`

Per-category rollup of the rules. `lost` is the score impact the category cost, `possible` the worst case, so `score` is the percentage the resume kept. Safe to expose: it says where the problem is without the rule-by-rule answer key.

<TypeTable
  type={{
    category: { type: "string", required: true },
    score: { type: "number", required: true },
    passed: { type: "number", required: true },
    total: { type: "number", required: true },
    lost: { type: "number", required: true },
    possible: { type: "number", required: true },
  }}
/>

## `AtsAdvice`

title: Package exports
description: Every subpath of @veriworkly/ats-engine, with what it exports, where it runs, its gzipped size and the peers it needs.

`@veriworkly/ats-engine` is ESM only and needs Node 22.12 or later. Each subpath below is a separate entry point, so a browser bundle takes only what it imports. Sizes are gzipped, for version <EngineVersion />, from the package's `sizes.json`.

## Summary

| Subpath                  | Holds                                                                          | Runs in                                                | Gzipped                                                                             | Peer needed                                                     |
| ------------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------ | ----------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `.`                      | Scoring, policy, input, report shaping, grounding, document types              | Browser, edge, Node                                    | about <EngineSize of="." whole />                                                   | None                                                            |
| `./document`             | Structured resume input                                                        | Browser, edge, Node                                    | <EngineSize of="./document" />                                                      | None                                                            |
| `./format`               | Display helpers                                                                | Browser, edge, Node                                    | <EngineSize of="./format" />                                                        | None                                                            |
| `./job`                  | Job posting text from HTML                                                     | Browser, edge, Node                                    | <EngineSize of="./job" />                                                           | None                                                            |
| `./locales`              | Language and region packs                                                      | Browser, edge, Node                                    | <EngineSize of="./locales" /> (`withLocales` alone <EngineSize of="withLocales" />) | None                                                            |
| `./ai`                   | Model-backed tasks                                                             | Wherever `fetch` exists, with the key kept server-side | <EngineSize of="./ai" />                                                            | None                                                            |

The core, `./document`, `./format`, `./job` and `./locales` make no network calls. The `ats-engine` command is the package's `bin`; see [Command line](/ats-engine/tools/cli).

Install the optional peers for PDF and DOCX on Node:

```bash
npm install pdf-parse@2 pdfjs-dist@5.4.296 mammoth
```

## `./node/child`

A process a server can fork and kill, which wraps `extractResume`. It has no `types` entry in the package exports, because it is a fork target rather than an import. Run it as a separate OS process, not a worker thread, so a crash or a forced kill on timeout stays contained.

It reads `{ id, format, buffer }` requests over the IPC channel of `fork` and answers each with one `{ id, ok, ... }` response, for as many requests as you send. It does not exit after a reply: kill it or disconnect from it when you are done, and it exits by itself when the parent disconnects. The buffer travels base64-encoded. `AtsExtractRequest` and `AtsExtractResponse` from `./node` type the messages.

```ts
import { fork } from "node:child_process";
import { createRequire } from "node:module";

const child = fork(createRequire(import.meta.url).resolve("@veriworkly/ats-engine/node/child"));
child.on("message", (response) => {
  console.log(response);
  child.disconnect(); // the child exits once the parent disconnects
});
child.send({ id: 1, format: "text", buffer: Buffer.from(resumeText).toString("base64") });
```

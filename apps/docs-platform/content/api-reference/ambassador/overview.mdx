## Description

A deliberately small surface today: applying to become a campus ambassador, and checking your
application status. There is no points, rewards, or redemption API. Applications capture college
name, graduation year (from last year to eight years ahead), and a few short free-text answers,
and are reviewed manually.

<Callout type="warn" title="Off by default in production">
  The entire group is gated behind a feature flag (`AMBASSADOR_PROGRAM_ENABLED`), which defaults
  **off** in production until explicitly enabled. Every route in this group returns `503` while the
  flag is off.
</Callout>

## Authentication

All routes in this group require a session cookie; none accept an API key.

## Available Endpoints

- `GET /ambassador/me`: [Get Ambassador Status](./getAmbassadorStatus)
- `POST /ambassador/apply`: [Apply For Campus Ambassador Program](./applyForAmbassador)

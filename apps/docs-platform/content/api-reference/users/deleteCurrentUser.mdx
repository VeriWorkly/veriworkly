title: Delete Current User
description: >
  Permanently deletes the authenticated user's account with its documents,
  portfolio, share

  links, API keys and profile, then clears the session cookies. This cannot be
  undone.


  Billing and payout records are kept, unlinked from the deleted account, for as
  long as the law

  requires: subscriptions, purchases, entitlement grants, the credit wallet and
  its

  transactions, affiliate commissions and withdrawals.


  Session only: a request authenticated with an API key is rejected with `403`,
  whatever its

  scopes. The request is refused with `409` while something could still charge
  the card or

  while the user holds an unpaid affiliate balance:


  - a subscription the billing provider still reports as active, on hold, past
  due or paused,
    or one created in the last 24 hours that is not paid yet: cancel it from Billing first. A
    subscription already set to cancel at the end of its period still blocks deletion until
    that period ends;
  - `details.code: "CHECKOUT_IN_PROGRESS"`: a checkout session is open; finish
  or cancel it
    first;
  - an affiliate withdrawal is requested or approved and not yet paid or
  rejected;

  - `details.code: "AFFILIATE_BALANCE_FORFEIT"`: deleting forfeits the unpaid
  commissions in
    `details.amountCents` (`availableCents` plus `pendingCents`, in `currency`). Show the
    amount, then repeat the request with `confirmAffiliateForfeit: true` and
    `confirmedAffiliateForfeitCents` set to the amount shown. If the balance has grown past
    that amount, the request is refused again with the new one.

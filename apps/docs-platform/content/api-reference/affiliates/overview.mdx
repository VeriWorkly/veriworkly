## Description

The affiliate program lets any user enroll, get a referral code, and earn a commission on payments
made by the users they refer, net of tax. The rate depends on the tier: 2% to start, 3% after 10
conversions, 5% after 50. Payouts are reviewed and paid by hand by an admin (bank transfer, PayPal,
and so on). The smallest withdrawal is $25.

- `POST /affiliates/referral` applies a referral code to the caller's account and answers
  `{ "applied": true }`.
- `GET /affiliates/me` includes `withdrawableCents`: the available balance minus any money owed
  back from a refunded commission. That is the most a withdrawal can be for.

<Callout type="warn" title="Off by default in production">
  The entire group is behind a feature flag (`AFFILIATE_PROGRAM_ENABLED`), which defaults **off** in
  production until explicitly enabled. Every route in this group, including the public ones, returns
  `503` while the flag is off.
</Callout>

## Authentication

| Method                                                  | Access Level      | Requirement                               |
| :------------------------------------------------------ | :---------------- | :---------------------------------------- |
| `POST /affiliates/click`, `GET /affiliates/leaderboard` | **Public**        | None.                                     |
| All other routes                                        | **Authenticated** | Session cookie only — no API key support. |

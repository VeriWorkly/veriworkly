title: Get Profile Import Quota
description: >
  Returns the caller's current GitHub and LinkedIn import quota status in one
  call. Requires

  the `resume:read` scope when called with an API key.


  - **GitHub import** is a real GitHub OAuth-backed integration (up to 30 of the
  account's most
    recently updated repositories, deterministically mapped to skills by repository language —
    no AI is involved). Free users get 1 import/day and may only import their own linked GitHub
    account. Paid users (any plan: AI Credits, Creator Pro or the Job Hunter Bundle, or a pass)
    may import any public GitHub username, but are capped at 50 imports/day, which protects the
    shared GitHub request budget every paid import uses. An account links one GitHub account,
    and a linked GitHub account cannot be removed.
  - **LinkedIn import** is not a LinkedIn API integration — it's an AI parse of
  raw text the
    user pastes in (copied profile text, or text extracted from an exported PDF). It costs the
    same AI credits as an ATS resume conversion, for every caller. Free users also get only 1
    import every 30 days; paid users have no import limit.

  Both import types share a single `replaceMaster` request flag and always
  create a brand-new

  RESUME document from the imported data, in addition to optionally overwriting
  the master

  profile.

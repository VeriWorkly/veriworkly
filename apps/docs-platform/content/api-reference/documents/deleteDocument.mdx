description: >
  Soft-deletes a document by setting `deletedAt`. The document is immediately
  excluded from

  list/get responses. Hard delete and restore exist at the service layer but are
  not exposed

  through any public route.


  `data` is `null` on success: the deleted document is not echoed back. Deleting
  a document

  that is already in the trash also answers `200`; only an id the caller does
  not own, or one

  already purged, answers `404`.

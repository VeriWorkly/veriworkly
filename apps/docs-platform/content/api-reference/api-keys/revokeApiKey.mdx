---
title: Revoke API Key
description: >
  Immediately disables an API key without deleting its record — `isActive`
  becomes false and

  `revokedAt` is stamped. The cached authentication record is purged at the same
  time, so the

  secret stops working right away rather than after the cache expires.


  A revoked key cannot be reactivated; rotate or create a new one instead.
  Revoking is

  idempotent: revoking a key that is already revoked, or was retired by a
  rotation, answers

  `200` again and keeps its original `revokedAt`. `data` is `null` on success.

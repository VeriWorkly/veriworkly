  Counts one product usage event (for example `resume_exported`) toward

  studio calls it

  from the browser.


  Public callers may send only the allow-listed event names listed under

  `auth_login_success`, cannot be

  reported. Trusted servers send `x-internal-key` instead of an API key, which
  also allows any

  other name, stored as `custom_<name>` (at most 50 distinct custom names per
  UTC day), and a

  `value` up to 1000.

title: Delete Portfolio Asset
description: >
  Deletes the R2 object and its metadata row. An asset created in the last 15
  minutes (the

  upload URL's lifetime plus 5 minutes) keeps its row, marked `DELETED`, so a
  late completion

  cannot revive it. `data` is `null` on success. Session-authenticated only.


  An image the published portfolio still shows cannot be deleted (`409`):
  publish without it

  first.


  This does not rewrite any portfolio that still references the asset — remove
  the reference

  and save the draft first, or publishing will fail with `400`.

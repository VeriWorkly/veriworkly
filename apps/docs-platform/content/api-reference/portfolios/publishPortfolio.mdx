title: Publish Portfolio
description: >
  Publishes the given draft revision to its chosen subdomain, making it publicly
  reachable.

  Premium templates (`nimbus`, `cipher`) need Creator Pro, the Job Hunter Bundle
  or a pass;

  `signal` and `atelier` are free. The stored draft is checked against the
  stricter publish

  rules (see `PortfolioDraftContent`).


  **Current-state caveat:** in production, publishing is gated behind a
  hardcoded

  `ADMIN_EMAIL` check independent of plan tier (`isAdminUser`) — regular users
  can save drafts,

  preview, and manage everything except actually flipping a portfolio live. This
  is a

  temporary rollout restriction, not a permanent product limitation. Only
  administrators can

  exercise this endpoint end-to-end in production today; outside production
  (`NODE_ENV` other

  than `production`) it is unrestricted. The restriction is checked before the
  body, so in

  production a non-admin gets `403` even for an invalid body.


  Checks run in this order: the premium-template `402`, then the stale-revision
  `409`, then

  the subdomain.

title: Liveness Check
description: >
  Lightweight liveness probe. Confirms the API process is up and responding.


  It deliberately touches **no** external dependency — no database query, no
  Redis command — so

  that frequent uptime polling does not keep database compute awake. It
  therefore cannot report

  on PostgreSQL or Redis, and never returns `503`. For dependency health use

  `GET /api/v1/health/ready`.


  It requires no session, no API key and no first-party origin, and it is not
  rate limited.

  The other fully open endpoints are listed in the introduction.

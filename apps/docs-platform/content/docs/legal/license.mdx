The VeriWorkly application source code is licensed under the **MIT License**.

<Callout type="warn" title="The MIT grant does not cover everything in the repository">
  Two things sit outside the MIT-licensed public code:

- **Portfolio templates** — Signal, Atelier, Nimbus, and Cipher live in a separate **private**
  repository (`VeriWorkly/portfolio-templates`) included as a git submodule at
  `apps/portfolio/template-library`. They are not part of the public MIT repository and the MIT
  grant does not extend to them.
- **Brand assets** — the VeriWorkly name, logo, and brand marks are not licensed for reuse under
  MIT.

Everything else — the marketing site, Studio, the portfolio application shell, the API server, the
shared UI package, the documentation, and the resume and cover letter templates — is MIT.

</Callout>

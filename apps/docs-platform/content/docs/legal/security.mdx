---
title: Security Policy
description: Where to read the VeriWorkly security policy and how to report a vulnerability.
---

The VeriWorkly security policy, including how to report a vulnerability, is published at
[veriworkly.com/security](https://veriworkly.com/security). That page is the only version, and it is
kept current there.

Please report a security issue privately as that page describes, not in a public GitHub issue.

For how sign-in, sessions, and rate limiting work, see [Authentication
System](/docs/architecture/auth-system).

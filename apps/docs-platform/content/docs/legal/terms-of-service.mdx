## 2. Scope of service

VeriWorkly provides a local-first career workspace: a resume and cover letter builder, a public
portfolio builder, an ATS checker, AI writing assistance, and a shared Master Profile. Cloud
synchronisation, sharing, AI, ATS scanning, profile import, and portfolio publishing are optional
features requiring an account.

Some features are gated by a paid entitlement. See
[Billing & Credits](/docs/product/billing-and-credits) for what each plan includes.

# Welcome to VeriWorkly

**VeriWorkly** is a privacy-first career workspace. It is a resume and cover letter builder, a public
portfolio/website builder, and the AI and career tooling that connects them — all built around one
shared **Master Profile**, so your career facts live in one place and flow into every document and
every portfolio.

You can start building without an account. Logging in adds optional cloud sync, sharing, AI, ATS
scoring, imports, and publishing.

## What is VeriWorkly?

VeriWorkly is built around a simple idea: career tools should not force people to trade privacy for
utility. Documents are written to your browser's `localStorage` first, so nothing is lost offline or
before you sign in. Cloud sync is opt-in per account, and can be disabled per document.

## Key Features

<Accordions>
  <Accordion id="free-open-source" title="Free & Open Source (MIT)">
    VeriWorkly is licensed under the MIT License. You can use it for free, modify it, and host your
    own instance. The codebase is on [GitHub](https://github.com/VeriWorkly/veriworkly). Note that
    the four **portfolio templates** live in a separate private submodule and are not part of the
    public MIT repository — see [Portfolio: Templates](/docs/product/portfolio/templates).
  </Accordion>

<Accordion id="no-account" title="No Account Required to Start">
  Open the builder and start writing. Guest sessions are backed by a 30-day HttpOnly cookie, so your
  work survives a page reload without an account. An account is only required for cloud sync,
  sharing, AI, ATS scanning, imports, and publishing.
</Accordion>

<Accordion id="master-profile" title="One Master Profile, Many Documents">
  Every new resume, cover letter, or portfolio auto-seeds from your Master Profile. Editing a
  document never writes back to it, so you can tailor a resume to one job without changing your
  canonical data. See [Master Profile](/docs/product/master-profile).
</Accordion>

<Accordion id="rich-customization" title="Rich Customization">
  Adjust accent and text colours, fonts, section spacing, page padding, and line heights. Show,
  hide, and reorder sections per document.
</Accordion>

  <Accordion id="self-hostable" title="Self-Hosting Ready">
    Deploy the marketing site, API, and Redis with the provided Docker Compose configuration and an
    external PostgreSQL instance. See [Docker Deployment](/docs/getting-started/docker-deployment).
  </Accordion>
</Accordions>

## Does the preview match the exported PDF?

Yes, by design. Each template is drawn twice from the same data and the same customisation
settings: once as HTML for the live paged preview, and once with `@react-pdf/renderer` for the PDF.
The PDF holds real, selectable text with embedded fonts. See [Export
Pipeline](/docs/architecture/pdf-generation) for how it works.

---

## What can I customise in a template?

Colours, fonts, spacing and which sections show. Every template honours the same settings:

- **Colours**: accent, body text, muted text, page background, section background, borders, and
  section headings, each independently set.
- **Typography**: font family (which drives PDF font embedding) plus body and heading line heights.
- **Spacing**: section spacing and page padding.
- **Structure**: per-section visibility, ordering, and heading labels.

See [Resume Schema](/docs/architecture/resume-schema#customization) for the full field list.

## Frequently asked questions

<Accordions>
  <Accordion id="ats-friendly" title="Are VeriWorkly resume templates ATS-friendly?">
    Yes. All seven resume templates are single-column with standard section headings, and the PDF
    export holds real text rather than an image, so an applicant tracking system can read it. They
    differ in look and density, not in how well they parse. For the format rules behind this, read
    [ATS-friendly resume format](https://blog.veriworkly.com/ats-friendly-resume-format).
  </Accordion>
  <Accordion id="two-column" title="Is there a two-column resume template?">
    No. Every resume template is single-column, because a second column is one of the layouts most
    likely to be read out of order by a parser. To check how your own file parses, run it through
    the [ATS Checker](/docs/product/ats-checker).
  </Accordion>
  <Accordion id="switch" title="Do I lose content when I switch templates?">
    No. A template only controls presentation. Your sections, entries and hidden sections stay
    exactly as they are, so you can switch between all seven templates on the same resume and
    compare them before exporting.
  </Accordion>
</Accordions>

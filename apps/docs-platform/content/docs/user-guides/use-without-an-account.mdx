**Yes. Open [app.veriworkly.com](https://app.veriworkly.com), choose Continue as Guest on the
sign-in screen, and start writing. Guest mode lasts 30 days per browser. Your documents are saved in
that browser, so no login is required to build and export a resume or cover letter. Backup,
sharing, ATS scans, imports and AI help need an account.**

## How do I start in guest mode?

Studio sends every visitor without a session or a guest cookie to the sign-in screen. Choose
**Continue as Guest** there. Studio sets a guest cookie and takes you to the page you were trying to
open. If that page needs an account, you land on the overview instead and a notice tells you why.

1. Go to [app.veriworkly.com](https://app.veriworkly.com).
2. On **Sign in to VeriWorkly**, select **Continue as Guest**.
3. Create a resume or cover letter from the dashboard.

## How long does guest mode last?

Guest mode lasts 30 days in the browser where you chose it. Studio stores a cookie named
`veriworkly-guest-mode` with a 30-day lifetime. When it expires, Studio shows the sign-in screen
again. Choose Continue as Guest to get another 30 days. The cookie only marks the browser as a
guest; your documents live in the browser's storage, not in the cookie.

## What can I do without signing in?

You can create, edit and export documents. A guest can keep one resume and one cover letter at a
time, the same limit as a free account. Exports (PDF, DOCX, HTML, Markdown, plain text and JSON) are
made in your browser, so they work in guest mode too. Everything you write stays in this browser.

## What needs an account?

The sign-in screen lists it: sign in to back up your documents to the cloud, share them, and use ATS
checks, imports and AI help. Three Studio pages also need an account: the Master Profile editor
(`/profile/master`), the Advanced JSON page (`/profile/advanced`) and the admin console.

| Feature                                      | Guest | Signed in         |
| :------------------------------------------- | :---- | :---------------- |
| Write and edit a resume or cover letter      | Yes   | Yes               |
| Export PDF, DOCX, HTML, Markdown, text, JSON | Yes   | Yes               |
| Cloud backup and sync across devices         | No    | Yes               |
| Share links                                  | No    | Yes               |
| ATS scans in Studio                          | No    | Yes               |
| LinkedIn and GitHub imports                  | No    | Yes               |
| AI writing help                              | No    | Yes, with credits |
| Master Profile and Advanced JSON pages       | No    | Yes               |

<Callout type="info" title="Want a quick ATS check without an account?">
  The public checker at [veriworkly.com/ats-checker](https://veriworkly.com/ats-checker) works
  without signing in. Inside Studio, the ATS page asks you to sign in before it scans.
</Callout>

## What happens to my guest documents when I sign in?

Nothing is uploaded until you choose. On your first sign-in, Studio finds the documents you made as a
guest and asks: **Add to my account**, **Keep on this device only**, or **Delete from this device**.
The dialog cannot be dismissed, and backup does not start until you answer it.

- **Add to my account**: the documents become yours and follow your account's automatic backup
  setting, like a new document.
- **Keep on this device only**: the documents become yours but stay in this browser, with backup
  turned off for each one.
- **Delete from this device**: the documents are removed. They are not saved anywhere else, so this
  removes the only copy.

If the browser also holds documents from a different account that signed in here before, Studio asks
about those separately and offers **Download a backup file first**.

## Can I lose guest documents?

Yes. Guest documents exist only in this browser's storage. Clearing this site's data, using a private
window, or switching browsers or devices leaves them behind. Export a JSON copy from the editor to
keep a backup you can import later, or sign in and add the documents to your account.

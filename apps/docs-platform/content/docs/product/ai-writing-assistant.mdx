**VeriWorkly's AI writing assistant rewrites a field or section, drafts resume sections and cover
letters, tailors a resume to a job post, and writes portfolio copy. Each run spends AI credits, the
cost is shown before you generate, and the draft never replaces your text until you choose to.**
Try it in the editor at [app.veriworkly.com](https://app.veriworkly.com).

## How do I use the AI writing assistant?

An "Improve with AI" control embedded throughout the editors. Select a field or section, choose **Standard** or **Expert** mode (different credit costs), optionally give free-text direction, and review the AI's draft before choosing to replace the field or discard it.

<Callout type="info" title="Cost is always shown before you spend it">
  The credit cost for the selected mode is shown on the mode buttons themselves, and again on the
  Generate button before you commit to spending credits. Generated content also never silently
  overwrites your work: replacing a field is always an explicit action.
</Callout>

AI writing runs on account credits, so it needs a signed-in account with a credit balance. Credits
come with a paid plan, a pass or a credit pack, available at launch. See
[Billing & Credits](/docs/product/billing-and-credits).

## What can the AI writing assistant do?

The server defines seven AI actions (`apps/server/src/services/aiTypes.ts`):

| Action                    | What it does                                                    |
| :------------------------ | :-------------------------------------------------------------- |
| `rewrite_short_text`      | Rewrites a short field, such as a headline.                     |
| `rewrite_section`         | Rewrites a whole resume section.                                |
| `generate_section`        | Drafts a resume section, such as a summary or experience entry. |
| `generate_cover_letter`   | Drafts a cover letter.                                          |
| `tailor_resume_to_job`    | Tailors a resume to a specific job description.                 |
| `generate_document`       | Drafts a whole document.                                        |
| `generate_portfolio_copy` | Writes portfolio copy (bio, headline, section copy).            |

Each action has its own Standard and Expert credit cost. `GET /api/v1/ai/actions` returns the
current costs, and the `/credits` page in Studio lists them.

Requests go through the OpenRouter gateway. The model chosen per request is set by the private AI
policy to balance quality against cost. It is not a user-facing setting.

## How are AI credits charged?

AI access is backed by a full credit ledger, not a boolean:

- **Standard vs Expert cost tiers**: Expert mode costs more credits per action.
- **Two-phase reserve → commit/release flow**: credits are reserved when a generation starts and either committed (on success) or released (on failure), so a failed generation doesn't burn credits.
- **FIFO multi-grant allocation**: if you have multiple active credit grants (e.g. a subscription grant plus a leftover top-up), a debit draws from the soonest-to-expire grant first, via a dedicated allocation table that records exactly which grant(s) funded each transaction.

One credit pool pays for every AI feature in every app. See
[Billing & Credits](/docs/product/billing-and-credits) for the full credit-wallet model.

## Self-hosting: where do AI costs come from?

Per-action prompts, model selection, token limits, and **credit costs for both modes** live in a
private AI policy loaded from configuration at boot, not in application code:
`AI_ACTIONS_POLICY_PATH` points at a file named `ai-actions-policy.json`, or
`AI_ACTIONS_POLICY_JSON` holds the same JSON inline. `GET /api/v1/ai/actions` exposes only the public
slice of that policy (the Standard and Expert credit cost of each action), which is what the editor
renders on the mode buttons.

The ATS feature keeps its own separate policies (`ATS_AI_POLICY_*` for the analysis prompts and
pricing, in `ats-ai-policy.json`; `ATS_ENGINE_POLICY_*` for the deterministic scoring rules, in
`ats-engine-policy.json`), so AI writing and ATS scoring can be configured and rotated
independently. The engine policy must be built for the engine version the server runs: the server
refuses to start with a policy its engine rejects. See
[Environment Variables](/docs/operations/environment-variables#private-ai-policies).

In production the server refuses to start unless `AI_API_KEY` is set and the policy defines both a
`standard` and an `expert` tier for **every** action.

## Is AI use rate-limited?

Yes, separately from credits.

AI endpoints have their own window and limit (`AI_RATE_LIMIT_WINDOW_MS` / `AI_RATE_LIMIT_MAX_REQUESTS`,
default 20 requests per minute) layered on top of credit and quota enforcement, plus a per-request
timeout (`AI_TIMEOUT_MS`, default 45 seconds).

## Can I call the AI from the API?

Yes, with an API key that has the `ai:write` scope.

The `ai:write` API-key scope is real and fully issuable: create a key with it at `/api-keys` in
Studio and call `POST /api/v1/ai/generate` programmatically. Generation through an API key spends the
owning account's credits exactly as the in-app flow does, so scope it deliberately. See
[API Keys](/docs/api-keys).

## Frequently asked questions

<Accordions>
  <Accordion id="generic" title="Will an AI-written resume sound generic?">
    It can, if you accept the first draft. Give the assistant specifics in the direction box (the
    tool, the numbers, the outcome) and edit what comes back. Practical tactics are in [using AI to
    write your resume without sounding
    generic](https://blog.veriworkly.com/using-ai-to-write-your-resume-without-sounding-generic).
  </Accordion>
  <Accordion id="failed-run" title="Do I lose credits if an AI request fails?">
    No. Credits are reserved when a generation starts and charged only when it succeeds. A failed or
    timed-out request releases the reservation, so the credits return to your balance. The full
    history of every charge and release is on the `/credits` page.
  </Accordion>
  <Accordion id="free-ai" title="Is the AI writing assistant free?">
    No. Every AI action spends credits, which come with a paid plan, a pass or a credit pack once
    payments open at launch. Everything else in the editor, including all templates and exports, is
    free. For how the credit system works, read [inside the AI credit
    system](https://blog.veriworkly.com/inside-the-ai-credit-system).
  </Accordion>
</Accordions>

**You can import into VeriWorkly from GitHub, LinkedIn, an existing resume file, JSON or Markdown.
GitHub import is a direct pull with no AI and no credits. LinkedIn import parses your pasted
profile text or exported PDF with AI and spends credits. Both create a new resume and can also
replace your Master Profile.** Start one in Studio at [app.veriworkly.com](https://app.veriworkly.com).

## How do I import my resume from GitHub?

Pulls a GitHub profile plus up to 30 recently updated repositories, and _deterministically_ (no AI) maps languages to skills and up to 15 repos to project entries.

| Tier | Limit                                                                                    |
| ---- | ---------------------------------------------------------------------------------------- |
| Free | Only your own linked GitHub account, once per rolling 24 hours.                          |
| Paid | Any public GitHub username, up to 50 imports a day (the counter resets at UTC midnight). |

`GET /api/v1/profiles/import/quota` reports the remaining imports for either tier.

<Callout type="info" title="One GitHub account per VeriWorkly account">
  You can link one GitHub account. Once linked, it cannot be unlinked or swapped for a different
  one; re-linking the same account to renew access is allowed. The GitHub account's email does not
  need to match your VeriWorkly email.
</Callout>

## How do I import my LinkedIn profile?

**Not an OAuth/API pull.** You paste your exported LinkedIn profile text (or upload a LinkedIn-exported PDF, which gets auto-extracted into the same paste box) and an AI call parses it into structured resume data.

Every LinkedIn import spends AI credits, at the same price as the ATS resume conversion. The modal
shows the cost and your balance before you run it. Credits are reserved first and charged only once
the import succeeds.

| Tier | Limit                                                 |
| ---- | ----------------------------------------------------- |
| Free | One import per rolling 30 days, plus the credit cost. |
| Paid | No import limit beyond the credit cost.               |

<Callout type="info" title='What counts as "paid" here'>
  Import limits check **entitlements**, not plan names: holding either `ai_credits` or
  `portfolio_publish` lifts the free-tier limits. That includes a manual admin grant or a time-boxed
  pass, not just a subscription. A credit pack does not lift them. Paid plans open at launch.
</Callout>

## Does an import overwrite my existing resume?

No. GitHub and LinkedIn import always create a new resume from the result and never change an
existing document in place. Both share one **"Replace my Master Profile with this data"** checkbox in
the same modal; leave it unchecked to keep your Master Profile as it is.

## Can I import an existing resume file?

Yes, in four ways:

- **Generic JSON import**: bring in a document exported from elsewhere, via the editor toolbar's Actions menu.
- **Markdown import**: a hand-authored markdown resume/cover-letter format, hand-parsed (section headers, date ranges, bold/italic stripping).
- **File extraction**: upload a PDF, DOCX, HTML, TXT, MD, or JSON resume (5 MB max, enforced server-side) and have its text extracted server-side for reuse. Used both standalone and inside the [ATS checker](/docs/product/ats-checker).
- **AI resume conversion**: paste or upload an existing resume in any format and have AI restructure it into a proper, editable VeriWorkly document. It spends AI credits and lives inside the ATS workspace rather than the main import modal.

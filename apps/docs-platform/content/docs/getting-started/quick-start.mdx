VeriWorkly is a monorepo with five Next.js applications (the marketing site, the studio, the
portfolio app, the docs and the blog), one Express/TypeScript API backed by PostgreSQL and Redis,
and two shared packages.

## Implementation paths

<Cards>
  <Card title="Local Development" icon={<Laptop />} href="/docs/getting-started/local-setup">
    Recommended for contributors. Run the workspaces manually to modify source code, test features, or
    design templates.
  </Card>

  <Card title="Docker Deployment" icon={<Server />} href="/docs/getting-started/docker-deployment">
    Recommended for self-hosters. Deploy the marketing site, the API, and Redis with the provided
    Docker Compose configuration and an external PostgreSQL instance.
  </Card>
</Cards>

## Architectural components

| Component          | Workspace                   | Role                                                                                                                      |
| :----------------- | :-------------------------- | :------------------------------------------------------------------------------------------------------------------------ |
| **Marketing site** | `@veriworkly/site`          | Landing, pricing, features, roadmap, FAQ, legal, affiliate and ambassador program pages.                                  |
| **Studio**         | `@veriworkly/studio`        | The workspace: resume and cover letter editors, Master Profile, ATS checker, AI tools, sharing, billing, API keys, admin. |
| **Portfolio**      | `@veriworkly/portfolio`     | The portfolio builder, its public template gallery, and the published portfolio sites.                                    |
| **Docs**           | `@veriworkly/docs-platform` | This site, built on Fumadocs.                                                                                             |
| **Blog**           | `@veriworkly/blog-platform` | The official blog, built on Fumadocs.                                                                                     |
| **API**            | `@veriworkly/server`        | Express API for auth, documents, billing, AI, ATS, sharing, portfolios, roadmap, changelog, and admin.                    |
| **Database**       | PostgreSQL                  | Primary store, accessed through Prisma. [Neon](https://neon.tech) works well for managed deployments.                     |
| **Cache**          | Redis                       | Sessions, rate limiting, quotas, buffered view counts, and distributed job locks.                                         |

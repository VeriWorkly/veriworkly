VeriWorkly is a privacy-first career workspace: resume and cover letter building, a public portfolio
builder, ATS scoring, AI writing assistance, and the shared Master Profile that connects them. This
documentation covers both the product's actual behaviour and the engineering behind it.

## Philosophy

- **Local-first, not login-first.** Documents are written to the browser first. With an account, cloud sync is on by default and can be turned off.
- **Ownership over lock-in.** Every document exports to six formats, including raw JSON.
- **Transparent AI.** Cost and mode are shown before generation; generated text never overwrites
  your work without an explicit action.
- **Open source.** The application code is MIT-licensed and publicly readable.

# VeriWorkly Developer & API Pricing

## API Access & Developer Keys

- **API keys are free**: any signed-in account can create keys (`vw_...`) at no cost.
- **Rate limit**: 20 requests per 15-minute window per key by default. A key can be set up to 600
  requests per 15 minutes.
- **Scopes**: `user:read`, `user:write`, `resume:read`, `resume:write`, `roadmap:read`,
  `changelog:read`, `github:read`, `ai:write`.
- **AI calls** (`ai:write`): any key can carry the scope, but each AI call spends AI credits from
  the account. There is one credit pool for every AI feature.

## Where AI credits come from (at launch)

Payments are not open yet; these are the prices at launch. The current offer is on
https://veriworkly.com/pricing.

- **AI Credits**: $5.99/mo, or $59.88/yr ($4.99/mo, save 17%). 1,000 credits a month.
- **Job Hunter Bundle**: $14.99/mo, or $143.88/yr ($11.99/mo, save 20%). 1,000 credits a month.
- **3-Day Sprint Pass**: $2.99, one time, 150 credits. **7-Day Hunt Pass**: $5.99, one time, 400
  credits.
- **Credit packs** (one time, valid 90 days): 250 credits $2.99, 500 credits $4.99, 1,200 credits
  $9.99. Packs are AI fuel only and unlock no Pro features.

Subscription credits reset every month and do not roll over. Annual plans grant their credits
monthly. Creator Pro ($9.99/mo or $95.88/yr) is the portfolio plan and includes no AI credits.

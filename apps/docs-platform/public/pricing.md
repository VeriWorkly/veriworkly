# VeriWorkly Developer & API Pricing

## API Access & Developer Keys

- **Free Tier API Access**: Up to 20 requests per 15-minute window per API Key (`vw_...`).
- **Scopes Included**: `user:read`, `user:write`, `resume:read`, `resume:write`, `roadmap:read`, `changelog:read`, `github:read`.
- **AI API Scope** (`ai:write`): Available on Pro subscription tiers (Job Hunter Bundle: $14.99/mo, or $143.88/yr, which is $11.99/mo).
